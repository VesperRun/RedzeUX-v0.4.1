# AI Disclaimer - Redze UX

## AI-Assisted, Not AI-Autonomous

Redze UX provides AI-assisted suggestions based on visible UI structure. It is an observational assistant and does not claim omniscient knowledge of product internals, analytics, or user psychology.

## Confidence Levels

- **High confidence:** Directly observed visible UI patterns
- **Medium confidence:** Heuristic interpretation of observed patterns
- **Advisory confidence:** AI suggestions that may be helpful but are not guaranteed

## Uncertainty Handling

Redze UX is designed to state uncertainty when evidence is limited, for example:

- "Insufficient visible evidence."
- "Cannot be reliably determined from observable UI alone."

## Bounded Inputs

Remote AI (if enabled) receives structured summaries only, not broad hidden-page context by default.

## No Guaranteed Outcomes

Redze UX does not guarantee conversion improvements, growth outcomes, retention changes, or other business results.

## Chrome Web Store Disclosure Language (Suggested)

Use this in your listing disclosures:

"Redze UX analyzes visible webpage UI structure locally in your browser to provide observational insights and advisory UX suggestions. It does not automatically collect browsing history or hidden private data. Optional AI features process structured summaries when enabled by the user."
