# Privacy Policy - Redze UX

Effective date: 2026-05-27

## Overview

Redze UX is designed to be local-first and privacy-first. The extension analyzes visible page UI structure to provide observational insights and advisory suggestions.

## What We Collect

- We do **not** automatically collect browsing history.
- We do **not** collect credentials, passwords, payment information, private messages, or hidden form values.
- We do **not** collect session tokens or secrets.

## Data Stored Locally

The following data may be stored in `chrome.storage.local`:

- `comparisonUrls` (only URLs users intentionally add)
- `panelOpen`, `panelMinimized`, `panelPosition` (floating panel state)
- `userSettings` (user-controlled extension preferences)

This local data remains until the user removes it or uninstalls the extension.

## AI Processing

By default, suggestions can be generated locally from structured observations.

If the user enables remote AI, Redze UX sends only a **structured summary** (not full raw page content). The summary may include:

- site type estimate
- detected visible feature names
- prominent/missing features
- possible friction observations

Redze UX is built to avoid transmitting hidden/private page data.

## Data Sharing

Redze UX does not sell personal data.  
Redze UX does not silently upload saved comparison URLs or browsing behavior.

## User Controls

Users can:

- Add/remove/clear comparison URLs
- Enable or disable remote AI
- Remove stored data by uninstalling the extension

## Compliance and Transparency

Redze UX follows transparency-first principles and is intended to align with Chrome Web Store policy expectations and common U.S. privacy expectations, including responsible privacy practices relevant for Texas users.
